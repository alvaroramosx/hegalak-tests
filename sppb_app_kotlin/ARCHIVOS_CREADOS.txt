================================================================================
🚀 CÓMO USAR
================================================================================

1. ABRIR EN ANDROID STUDIO:
   File → Open → Selecciona carpeta sppb_app_kotlin

2. ESPERAR SINCRONIZACIÓN:
   Gradle sincronizará automáticamente (2-5 min primera vez)

3. EJECUTAR:
   Run → Run 'app' (Shift+F10)
   O haz clic en el botón ▶️ verde

4. PROBAR:
   Sigue el flujo: Datos → Equilibrio → Marcha → Silla → Resumen

5. EXPORTAR:
   En resumen, haz clic en "Enviar a Drive / Exportar"
   Los archivos se guardan en:
   /storage/emulated/0/Android/data/com.sppb/files/output/

================================================================================
📊 PUNTUACIÓN SPPB (RECORDATORIO)
================================================================================

EQUILIBRIO (0-4):
  0 = No mantiene 10s pies juntos
  1 = Mantiene 10s pies juntos, no semitándem
  2 = Mantiene 10s semitándem, < 3s tándem
  3 = Mantiene 3-9.99s tándem
  4 = Mantiene 10s tándem

MARCHA (0-4):
  0 = No puede / > 8.70s
  1 = > 8.70s
  2 = 6.21-8.70s
  3 = 4.82-6.20s
  4 = < 4.82s

SILLA (0-4):
  0 = No puede / > 60s
  1 = ≥ 16.70s
  2 = 13.70-16.69s
  3 = 11.20-13.69s
  4 = ≤ 11.19s

TOTAL (0-12):
  0-4  = Fragilidad alta     🔴
  5-8  = Fragilidad moderada 🟡
  9-12 = Fragilidad baja     🟢
